TC Wiper - version history
==========================

1.0.2 beta (2026-11-10)
  * New TCWiperGo.exe for a hotkey or button without Autorun: a Total
    Commander user command passes it the selected items with %WL, and it
    wipes them with the usual confirmation. Works with 32-bit and 64-bit TC.
  * WiperGo returns -1 when some items were not erased (file in use, hard
    links, protected folder) and 1 when Cancel was pressed during the wipe;
    before, it returned 0 in both cases. Reported by Orion9.

1.0.1 beta (2026-11-09)
  * New exported function WiperGo for scripts running inside Total Commander
    (e.g. Autorun): wipes the selected files and folders of the active panel,
    or the item under the cursor, with the usual confirmation. Returns
    0 = wiped, 1 = cancelled, 2 = nothing selected, -1 = error (message shown).
    Requested by Orion9 on wincmd.ru.
  * Folder links (junctions) inside wiped folders: only the link is removed.
  * Empty folders inside Windows and Program Files are no longer removed.

1.0.0 beta (2026-10-28)
  * First public release (beta: tested by the author only).
  * Plugin panel shows "Move here to securely wipe", Readme.txt and Readme_ru.txt.
  * F6 (Move) into the panel: confirmation with number of files and folders and
    up to 5 selected names; nothing is touched before you confirm.
  * Each file: one pass of cryptographic random data including cluster slack and
    alternate data streams, flush, truncate, 3 random renames, delete.
    Emptied folders are renamed and removed.
  * Progress window with Cancel; summary with reasons for files not erased.
  * Protected: Windows and Program Files folders, hard-linked files, files in use.
    Symbolic links: only the link is removed.
  * F5 (Copy) never erases anything.
  * 32-bit (.wfx) and 64-bit (.wfx64) versions, Unicode and long path support.
  * Developed using Claude Opus 5.5 Medium (Anthropic).
